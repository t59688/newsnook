# AI 速读三评（讽世 / 析世 / 观世）设计

## 目标

在现有 AI 速读事实总结之外，同一轮生成再输出三条风格固定的一句话评论，并让面板、复制、Markdown 导出与分享图共用同一份正文。分享图里三评紧接在「有所闻」之后、重点脉络之前。

## 硬约束

- 本地优先：不新增云端必经路径；仍走用户自配的 OpenAI 兼容接口。
- 同一轮最终 completion 产出；不为三评单独再开请求。
- 长文分段笔记仍只抽事实，不下结论、不写三评；三评只出现在最终速读。
- 不引入生产依赖；不改账户 / 云同步边界。
- 继续禁止 emoji、外链、编造事实；正文仍视为不可信数据。
- `PROMPT_VERSION`  bump，避免旧缓存（无三评）被当成新结果。

## 输出契约

固定六个二级标题，顺序不可变：

1. `## 有所闻` — 1–2 句读感与核心判断（既有）
2. `## 讽世` — 恰好一句，约 20–40 字
3. `## 析世` — 恰好一句，约 20–40 字
4. `## 观世` — 恰好一句，约 20–40 字
5. `## 重点脉络` — 3–6 条（既有）
6. `## 值得注意` — 既有规则；没有则「暂无额外需要注意的信息」

### 三评人格

| 标题 | 任务 | 风格参照 | 擅长 | 表达 | 批判 |
|---|---|---|---|---|---|
| 讽世 | 判现实 | Oscar Wilde / 鲁迅 / 林语堂 | 一针见血 | 隐喻 | 讽刺幽默 |
| 析世 | 判结构 | George Orwell / 钱钟书 / 费孝通 | 拆因果 | 类比 | 冷静解剖 |
| 观世 | 判处境 | Montaigne / 加缪 / 汪曾祺 | 换框 | 场景 | 反问 |

每条从文中抓一个词或概念做切口，一句话点破；不重复「有所闻」原句；无从下口时写「暂无额外可评」，不得空标题。

## 方案

推荐：**扩展同一份 Markdown 契约**，提示词、解析、分享卡一起认新标题。

1. **`sections.ts`**  
   在既有 `SPEED_READ_SECTION_TITLES` 上增加 `satire` / `structure` / `situation`（文案：讽世 / 析世 / 观世），供 prompt、解析、分享卡共用。

2. **`service.ts` 最终 system prompt**  
   - 固定六个二级标题及顺序。  
   - 为三评各写清人格与「一句 / 抓词 / 不编造」约束。  
   - 既有抗注入与「只依据文章」规则保持。  
   - `chunkSystemPrompt` / 合并笔记 prompt 不变。

3. **缓存**  
   `PROMPT_VERSION`：`speed-read-v2` → `speed-read-v3`。用户重新生成后才有三评。

4. **解析与分享图**  
   - `ParsedSpeedRead` 增加 `satire` / `structure` / `situation` 三个字符串字段。  
   - `parseSpeedReadMarkdown` 按标题归类；缺段时对应字段为空字符串。  
   - 四种分享样式（warm-paper / editorial / dusk / journal）均在「有所闻」块后插入紧凑三评带：左标签、右一句；再接重点脉络 / 值得注意。  
   - editorial 的 `02` / `03` 仍只标重点脉络与值得注意；三评不占大编号，避免卡片变成六段目录。

5. **面板 / 复制 / `.md` 导出**  
   继续渲染或导出完整 body Markdown，无需单独 UI 状态；流式展示随正文自然出现。

## 数据流

```text
正文 HTML
  → normalize /（必要时）分段事实笔记
  → 最终 chat（新 system prompt）
  → serializeSpeedRead（thinking + body）
  → 缓存 / 面板 Markdown / 复制 / .md / parse → 分享图
```

## 错误与降级

- 模型漏写某一评：解析为空串；分享图该行统一显示「—」，不阻断整张卡。
- 模型主动写「暂无额外可评」：按正常正文展示，不改写成「—」。
- 模型把三评写成多句：展示层不截断（避免误伤标点）；靠 prompt 约束长度。
- 生成失败 / 取消：沿用现有 error / cancelled 路径；不半写缓存。

## 测试

- `sections` 标题常量与 prompt 使用一致。
- `parseSpeedReadMarkdown`：六段齐全、缺三评、旧三无三评正文均可解析且不把三评吞进结论或要点。
- 分享卡 HTML：四种样式均在「有所闻」后、重点脉络前出现讽世 / 析世 / 观世。
- `PROMPT_VERSION` 变更后 cache key 与 v2 不同。
- 现有 `speed-read` 相关测试更新样例后仍通过。

## 非目标

- 不为三评增加独立设置项、独立模型或二次请求。
- 不把三评同步上云。
- 不改文章分享短链 / OG 卡片（仅 AI 速读分享图与速读导出）。

## 完成标准

- 新生成的速读 body 含固定顺序的六段标题；三评各为一句中文。
- 面板、复制、Markdown 导出可见三评。
- 四种速读分享图在「有所闻」之后展示三评。
- 旧缓存因 prompt version 失效；相关单测与 lint / 类型检查通过。
