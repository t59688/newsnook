# LinuxDo 完整发帖编辑器设计

## 目标

把 LinuxDo 工作区现有的最小 Markdown 输入框升级为可正式交付的移动端发帖编辑器，覆盖新主题、回复和编辑三条路径，并保持现有登录、草稿、上传与发帖 API 契约不变。

## 体验方向

- 采用克制、紧凑的编辑工具风格：信息密度参考 LinuxDo PWA，触控热区、底部抽屉和安全区适配遵循 Android App 习惯。
- 新主题编辑器占满可用工作区；标题、分类、标签、工具栏、正文和提交状态形成清晰的从上到下流程。
- 回复与编辑复用同一编辑内核，但隐藏不适用的标题、分类和标签字段。
- 编辑与预览一键切换；预览覆盖基础 Markdown、表格、代码块、Details、Spoiler、投票、日期以及图表源码占位。

## 功能范围

1. 标题最少 6 个 Unicode 字符、正文最少 20 个 Unicode 字符，界面持续显示计数与缺口。
2. 分类支持搜索、颜色标识、描述和主题数；允许不指定分类。
3. 标签支持搜索、已选管理和在无精确匹配时创建新标签，最多 5 个。
4. 工具栏支持标题、粗体、斜体、删除线、链接、引用、行内代码、列表、撤销与重做。
5. 图片/附件继续走现有原生分块上传，并把 Markdown 插入当前光标位置。
6. `+` 菜单提供整帖引用、预格式化、表格、目录、滚动内容、Mermaid、Chart、详情、Graphviz、日期/时间、公式、模板、脚注、模糊剧透、投票和硬换行。
7. 自动草稿保存继续使用现有 Discourse draft key/sequence；恢复标题、正文、分类和标签。
8. 关闭含未保存内容的编辑器时二次确认；发布、上传与草稿冲突提供可读中文错误。
9. 不新增生产依赖，不改变 LinuxDo 发帖、草稿和上传的外部协议。

## 边界

- 编辑器保存的唯一真相仍是 Discourse Markdown/BBCode 原文，不引入独立富文本文档格式。
- 图表、Mermaid、Graphviz 等插件能力以合法源码块插入；本地预览提供明确占位，最终渲染以 LinuxDo 服务端能力为准。
- 不把 LinuxDo 内容或草稿写入 NewsNook Cloud。
