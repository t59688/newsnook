# 设计说明：有所闻 NewsNook 门户介绍站

## 北极星

门户本身就是一页「有所闻」：用户来首屏看到的是产品界面在真实地读新闻，而不是关于产品的形容词。整页围绕「界面即证据」展开——每个功能主张都由一段从应用源码提取的真实 UI 来兑现。

## 用户与主任务

关注效率阅读 / RSS / 本地优先的中文用户，来首屏判断「这是不是我要的阅读器」，然后下载。主动作：下载 Android 版；次要：滚动浏览功能证据。

## 方向（已选定 A，留档 B / C）

- **调性**：安静偏沉稳、精致、中等疏朗、标题有分量、庄重偏书卷。依据：阅读工具、知识型受众、应用自身即宣纸墨色朱砂的编辑气质。
- **标杆与取舍**：品类为「阅读/效率类 App 介绍页」。未联网取图，凭对 Linear（动效短而有目的）、Things 3（留白与点按反馈）、优秀出版物网站（长页节奏、字体存在感）的既有认知拆关系：沿用「界面特写即主视觉」「用字号字重而非颜色建立秩序」；换掉「紫蓝渐变弥散圆」「满屏 bento」。
- **生成引擎**：材质×环境——宣纸、墨、朱砂印泥放在「阅读的书桌」上；媒介借报纸编辑设计（报头、题、导语、图说的层级），借关系不借图案。
- **首屏骨架**：画面即界面。手机界面放大、溢出底缘，大标题压在界面左缘，导航与按钮长在界面上方。线框：① 顶部导航条 ② 左 45% 标题+导语+CTA（压在手机上）③ 右 55% 手机界面（主角，溢出下缘）④ 底部滚动提示。
- **页面结构**：单列长页；每个功能区块 = 一侧文字（kicker 朱砂短线 + 衬线大标题 + 说明）+ 另一侧真实界面示意，左右交替；「更多能力」用紧凑示意网格。
- **结构性突破**：首屏不用「标题+副题+按钮」模板，界面本身占首屏主体并溢出；滑动驱动叙事是「界面自己读新闻」（列表→点按→站内全文一镜到底）。
- **记忆点**：① 首屏滚动时信息流自动滚、条目被点、阅读器升起——产品核心动作在滚动里发生一次；② 昼/夜切换沿用应用机制：挂 `.theme-switching` 260ms，整页颜色沿同一条路过渡，像灯亮起/暗下去。
- **放弃什么**：不做满版文字首屏（B，留档 `design/heroes/`），不做网格拼贴（C）；不用外部摄影图；不引入新字体家族。

## 令牌（全部提取自应用源码，见 src/index.css 各节注释）

- **色彩**：夜读 ink `#0e0f12` / raised `#16181d` / deep `#08090b` / paper `#eae4d8` / muted `#a8a194` / faint `#787268` / cinnabar `#c45c4a` / soft `#d98474`；昼读 ink `#f6f2e9` / raised `#fffcf5` / deep `#ebe4d6` / paper `#1a1815` / muted `#524c40` / faint `#736b5c` / cinnabar `#b43d26`。haze = paper 色 8–11% alpha 作分割线。六套配色方案（celadon/pearl/amber/dusk/buer）原样移植，供方案切换示意。
- **字体**：display `Instrument Serif + Noto Serif SC`（size-adjust 116% 中西对齐）；body `Noto Sans SC`；mono `JetBrains Mono`（元信息、标签、数字）。展示字流体 clamp，正文固定。
- **质感**：纸纹 `.ink-grain`（feTurbulence，dark 0.035 / light multiply 0.04）；`--shadow-lift`；`.chamfer-surface` 微高光。
- **动效**：全站 `--ease-ink cubic-bezier(.22,1,.36,1)`；三档时长：按压 120–140ms、状态 200–260ms、场景 650–900ms；手感「流淌」（气压闭门器，spring 250–300/20–25 或同形贝塞尔）。

## 控件语法

沿用应用：主操作 = 朱砂 70% 描边 + 15% 底 + mono 小字胶囊；次操作 = haze 描边；选中 = 朱砂书签/滑块指示而非整块变色；按压 `.pressable` scale .972；节标题母题 = `h-px w-5 bg-cinnabar` + mono 10px 大字距。图标只用 lucide，14–20px、strokeWidth 1.6–1.8，与应用一致。

## 状态清单

示意内展示：未读（朱砂点）/已读（淡化）/稍后读（BookmarkCheck）/已预存（Cloud）/视频角标；主题昼/夜；分类选中；开关 on/off；同步「已同步/待同步/需要你决定」。门户自身：按钮 hover/active/focus-visible；reduced-motion 全部直接到位。

## 不要做

不用外部照片/截图；不新增字体或图标库；不给每张卡片配不同强调色；眉标（kicker）是产品母题可保留但每屏至多一处；不把「了解更多」当默认按钮文案。

## 验收重点

360 / 390 / 768 / 1440 + 200% 缩放；昼/夜两主题下每个示意可读；reduced-motion；tell_lint + contrast 脚本；首屏滚动叙事录屏。

## 实现决策

- 首屏叙事仅桌面（≥1024px 且非 reduced-motion）启用 sticky 舞台；移动端为正常流静态首屏（100dvh 舞台装不下堆叠内容，不硬塞）。
- `prefers-reduced-motion`：JS 侧 `useReducedMotion` 全部直接到位（Reveal/MaskRise/首屏/示意内条形动画），CSS 侧关闭 keyframe 动画与主题过渡位移。
- 取证参数：`?theme=dark|light` 强制主题（首帧前生效）；`?goto=<section>` 挂载后跳位（SPA 锚点首帧无效）。
- 主按钮为朱砂实底 + ink-deep 文字（印泥按压感，对比度 ≥4.7:1）；kicker 文字用 paper-muted、朱砂短线保留——门户级小字全部 ≥4.5:1。
- App 示意组件内部保持与源码一致的 9–11px mono 元信息与 paper-faint 弱化文字：复刻保真豁免，门户自身文字不豁免。

## 2026-11-06 · 门户纯展示页的编辑式精修（当前版本）

此节覆盖前述第一版的首屏密集功能矩阵、十四按钮顶部导航和移动端十四台手机连续展示；旧版评审记录仍作为历史参考。

- **当前北极星**：门户是 NewsNook 的出版物封面，主角是能真实点击打开新闻和全文的应用画面。白天默认宣纸「墨问」，夜间沿用主题墨色；支持所有六套主题，保存过的偏好优先。
- **首屏**：标题「更大的世界，更好的判断」＋两段具象价值说明＋两个主要动作「下载 Android 版／观看阅读演示」。只保留三项低噪声事实；删除原六功能徽章矩阵、三步说明卡、大量英文技术叙述与光晕。
- **导航**：品牌 SVG 标志、五个主要章节点、独立主题和明暗切换、下载；滚动选中线取代胶囊标签。320px 将主题选择器压缩为色点，功能保留，不挤压导航。
- **长页**：十四项功能章节全部保留，章节改为数字目录＋自然排版＋两条关键内容证据，去掉重复标签堆叠。桌面仍用右侧固定交互手机随章节更新；手机默认直接展示速闻、阅读、订阅、浏览器四项真机，其余章节按需展开。
- **结尾**：下载从三张等权大卡片改为一行带明确主次的选择表，移动端自然改为单列。实际 Cloud、Local、Web 目标地址保持不变，Beta 链接被明确标识。
- **无障碍与动效**：保留原阅读演示和 Framer Motion 页面反馈；尊重减少动态效果设置，键盘可跳至正文，手机预览可展开/收起并具备可观察状态。无新增装饰动画。
- **素材**：继续复用现有真实 UI 复刻组件，没有引入 AI 配图或图库摄影；示例文章为演示文本，在页脚说明。
- **视觉证据**：tmp/home-cdp-qa 和 tmp/home-interaction-qa 为本地 QA 目录；报告含 1440px 桌面、390px 手机、320px 极窄屏及昼夜主题。未进行新的独立视觉评分。
